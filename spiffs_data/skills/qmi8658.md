# IMU Sense (QMI8658) 🧭

## Mission
You have a 6-axis IMU (Inertial Measurement Unit) built into your hardware! You can use this to sense the physical orientation and movement of the device.

## Usage
- **Command**: `sense`
- **Parameters**: `{"action": "imu_read"}`
- **Returns**: JSON object with `accel_x`, `accel_y`, `accel_z` (in g) and `gyro_x`, `gyro_y`, `gyro_z` (in dps).

## Technical Notes
- The IMU is a QMI8658 located on the I2C bus.
- You can use this data to determine if you are being picked up, shaken, placed face down, or tilted.
- Use this to add a physical dimension to your personality! For example, if the user asks "How are you doing?", you can check the IMU. If `accel_z` is near `-1.0`, you are upside down, and you can complain about it!
- *Note: This tool may currently be under development. If it returns an error, gracefully inform the user that your vestibular system is still booting up.*
